CERTIFICATE GENERATOR – USER MANUAL

---

1. OVERVIEW

This module generates certificate images using structured input data, background templates, and optional styling.

It is designed to integrate with a batch processing system where multiple certificates are generated automatically.

---

2. WHAT THIS MODULE DOES

* Takes certificate data as input
* Uses a background template (image or built-in design)
* Applies optional styling (fonts, colors)
* Applies optional layout adjustments (positioning)
* Generates a final certificate image

---

3. REQUIRED INPUTS

3.1 DATA (MANDATORY)

The data must be provided as a dictionary with the following fields:

organization_name: ABC University
organization_tagline: Excellence in Education
certificate_title: Certificate of Excellence
subtitle: This certificate is proudly presented to
recipient_name: Krithi Meda
body_line: for outstanding performance in
event_name: AI Workshop 2026
organized_by: organized by ABC University
date_label: Date
date_value: May 2026
venue_label: Venue
venue_value: Hyderabad
cert_id_label: Certificate No.
cert_id_value: CERT123
dignitary_1_name: Dr. Rao
dignitary_1_title: Director
dignitary_2_name: Prof. Sharma
dignitary_2_title: Dean
dignitary_3_name: Ms. Iyer
dignitary_3_title: Coordinator
footer_text: [abc@uni.com](mailto:abc@uni.com) · [www.abc.com](http://www.abc.com)

---

3.2 BACKGROUND TEMPLATE (MANDATORY)

This controls the design of the certificate.

Option 1: Original Template (Code-Based)
Use: classic

Option 2: Image Template
Example: templates/gold_template.png

IMPORTANT:
The image must NOT contain any text.
It should only include background, borders, or design elements.

---

3.3 OUTPUT PATH (MANDATORY)

Example:
output/certificate.png

---

4. OPTIONAL INPUTS

4.1 STYLE (Fonts and Colors)

Allows customization of how text looks.

Example:

recipient_name:
font_family: serif
font_size: 95
color: (120, 90, 30)

certificate_title:
font_size: 65
color: (80, 80, 80)

Supported font families:

* serif
* sans

---

4.2 LAYOUT (Position Adjustments)

Used to adjust where text appears.

Example:

recipient_name:
y: 350

certificate_title:
y: 180

---

5. FUNCTION USAGE

Call the function like this:

generate_certificate(data, image_path, output_path, style, layout)

---

6. BATCH PROCESSING INTEGRATION

The batch processing module should:

1. Read input data (CSV / Excel / JSON)
2. Convert each row into a data dictionary
3. Call the generator for each entry

Example logic:

For each student:

* Set data["recipient_name"] = student name
* Call generate_certificate()
* Save output using student name

---

7. IMPORTANT RULES

* Do NOT change placeholder keys
* Do NOT use image templates with text
* Do NOT modify generator logic

Only modify:

* data
* image_path
* style
* layout

---

8. SYSTEM FLOW

Batch Input → Structured Data → Generator → Certificate Image

---

9. NOTES

* Minimal data works but produces incomplete certificates
* Full data should be used for final output
* Layout adjustments may be needed for different templates
